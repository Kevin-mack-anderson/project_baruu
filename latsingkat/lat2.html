Apa Itu HTML?

HTML adalah Hyper Text Mark-up Languange yang menjadi kerangka dari sebuah website, tanpa adanya HTML maka isi dalam website menjadi tidak terorganisir dengan baik. Informasi Selengkapnya

Kapan Penggunaan HTML?

Apa Itu CSS?

CSS (Case Cading Style Sheet) adalah sebuah bahasa yang digunakan untuk mendesain tampilan antarmuka website menjadi lebih menarik, CSS mampu memanipulasi tampilan dari setiap element HTML yang ada.

Apa itu JS?

JS (Javascript) adalah sebuah bahasa pemograman yang dibuat dengan tujuan menambahkan interaktif website. Dibuat oleh sun micro system dan yang menariknya, Javascript tidak ada kaitannya dengan bahasa pemograman Java.
